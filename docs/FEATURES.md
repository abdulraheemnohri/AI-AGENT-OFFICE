# Product feature inventory

Writer: rich text, pagination, styles, tables, images, headers/footers, footnotes, TOC, citations, mail merge, comments, track changes, comparison, templates, print and DOCX/DOC/ODT/RTF/TXT/Markdown/PDF.

Sheets: workbook tabs, grid, formula engine, dependency recalculation, formatting, named ranges, sorting/filtering, validation, conditional formatting, pivot tables, charts and XLSX/XLS/ODS/CSV/TSV.

Slides: slide canvas, layouts, themes, master slides, shapes, images, charts, tables, layers, notes, transitions, animations, presenter mode and PPTX/PPT/ODP.

PDF Studio: reader, search, bookmarks, annotations, highlights, page insert/delete/reorder/rotate, merge/split, compression, forms, signatures, watermarks, metadata and OCR.

Other tools: image editor, SVG/diagram studio, flowcharts, mind maps, SQLite/SQL studio, file manager, batch conversion, templates, printing and archive inspection.

AI: local chat, writing, rewriting, grammar, translation, summarization, document Q&A, cross-file analysis, formula generation, chart suggestions, slide generation, OCR, table extraction, embeddings, RAG, citations, speech recognition and synthesis.

Agents: task planning, approval gates, scoped file tools, batch jobs, workflow builder, triggers, conditions, retries, logs, history and scheduled local jobs.

Model management: import/download, checksums, catalog, capabilities, quantization metadata, storage, versions, benchmarks, load/unload and resource configuration.

Runtime catalog: llama.cpp, ONNX Runtime, ONNX Runtime GenAI, OpenVINO, LiteRT/TFLite, DirectML, CUDA, Vulkan and WebGPU. All adapters are planned, not active in the foundation.

Formats must be labeled native edit, import/edit, read-only or export-only. Unsupported structures must warn and preserve originals.
